# Code Review Skill

## 目标

按照生产级 AI 全栈工程标准审查变更。

## 检查清单

检查：

- 变更是否符合仓库结构。
- 类型是否严格且有意义。
- 边界输入是否用 Zod 校验。
- secret 是否只在服务端使用。
- 模型调用是否都经过 `src/server/ai`。
- 可复用 prompt 是否放在 prompt 模块。
- 工具调用是否安全、可观测。
- RAG chunk 和 retrieval 结果是否可追踪。
- UI 是否处理 loading、empty、error、success 状态。
- 错误是否归一化。
- 有意义时是否添加测试或 eval。
- 行为变化是否更新文档。
- 是否引入了不必要依赖。
- 是否有重复逻辑。

## 输出格式

返回：

1. 严重问题
2. 建议改进
3. 已验证项目
4. 运行过的命令
5. 剩余风险
